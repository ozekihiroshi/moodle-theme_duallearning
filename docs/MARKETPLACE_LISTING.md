# Dual Learning theme Marketplace listing

## Name

Dual Learning

## Component

theme_duallearning

## Short description

Dual Learning is a polished, lightweight Boost child theme for comfortable learning, clear keyboard focus, and dependable narrow-screen use.

## Full description

Dual Learning gives Moodle a calm, coherent learning-workspace appearance while keeping its familiar Boost layouts, navigation, course index, activity controls, submission pages, and grade reports. A restrained teal visual system, balanced spacing, clear content surfaces, and a local system-font stack help both students and teachers experience the site as a considered learning product.

The theme supports teacher-guided sessions and self-paced study. It gives keyboard focus a consistent visible outline, improves the standard dashboard, keeps wide tables and diagrams accessible with local scrolling, gives LessonMark presentations a wide teaching surface, and improves long-form typography in LessonMark, Page, and Book resources.

The theme does not introduce JavaScript, downloaded fonts, CDN requests, custom renderers, external services, or tracking. It can be used with Moodle's standard course formats and does not require the Dual Learning course-format plugin.

## Installation

Upload the ZIP through Site administration > Plugins > Install plugins, or extract its single duallearning directory into Moodle's theme directory. Complete the Moodle upgrade and choose Dual Learning from the standard theme selector. No Composer, npm, or post-install build step is required by the administrator.

## Requirements

- Moodle 5.2
- Boost, included with Moodle
- No external service or additional plugin dependency

## Privacy

Dual Learning does not store personal data. The package implements Moodle's Privacy API null provider.

## Known limitations

- The declared compatibility is limited to the tested Moodle 5.2 line.
- The theme inherits Boost layouts and settings and provides no separate settings page.
- Course content translations remain the responsibility of the course or the plugin that supplies each string.
