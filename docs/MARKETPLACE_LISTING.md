# Dual Learning theme Marketplace listing

## Name

Dual Learning

## Component

theme_duallearning

## Short description

Dual Learning is a lightweight Boost child theme that improves keyboard focus visibility and keeps learning content usable on narrow screens without changing Moodle's standard navigation.

## Full description

Dual Learning supports courses that combine teacher-guided sessions and self-paced study. It keeps Moodle's familiar Boost layouts, navigation, course index, activity controls, submission pages, and grade reports. Its small presentation layer gives keyboard focus a consistent visible outline and constrains common learning media and code blocks so that course content remains available on narrow screens.

The theme does not introduce JavaScript, external fonts, CDN requests, custom renderers, data tables, external services, or tracking. It can be used with Moodle's standard course formats and does not require the Dual Learning course-format plugin.

## Installation

Upload the ZIP through Site administration > Plugins > Install plugins, or extract its single duallearning directory into Moodle's theme directory. Complete the Moodle upgrade and choose Dual Learning from the standard theme selector. No Composer, npm, or post-install build step is required by the administrator.

## Requirements

- Moodle 5.2
- Boost, included with Moodle
- No external service or additional plugin dependency

## Privacy

Dual Learning does not store personal data. The package implements Moodle's Privacy API null provider.

## Known limitations

- The declared compatibility is limited to the tested Moodle 5.2 line.
- The theme inherits Boost layouts and settings and provides no separate settings page.
- Course content translations remain the responsibility of the course or the plugin that supplies each string.
